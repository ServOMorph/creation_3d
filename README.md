# creation_3d

Protocole local de création et d'animation de modèles 3D, avec des IA locales uniquement.

## État actuel
Phases 0 à 2 terminées : pipeline MPFB2 → Kimodo → retarget Blender → GLB/FBX → rendu Cycles, importé dans Godot 4.5 et Unreal 5.7. Prochaine phase : benchmark de génération 3D. Voir `roadmap_creation_3d.md`.
